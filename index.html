Practice tools

Truth Table Trainer

Build a truth table one column at a time, the way you would on paper. It makes you work out how many rows you need, enumerate them yourself, and decide which column can be computed next — then checks each column as you go.

Covers every kind of truth-table question in the course:

  • classifying sentences as tautology, contradiction, or contingent
  • finding which sentences are equivalent and which mutually exclusive
  • testing whether an argument is valid — including finding the counterexample row
  • presence/absence tables for the week 3 property questions

Sample questions of each type are built in, or you can type your own. You control how much help you get — turn the hints off one at a time as you improve, or switch on exam mode, which gives no help at all and checks nothing until you submit.
